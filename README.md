# Micro-servicios-NovaPlay
Desarrollé una arquitectura de microservicios en Spring Boot para una tienda de videojuegos. Implementé Eureka, API Gateway, comunicación con OpenFeign y persistencia con JPA. Apliqué arquitectura limpia (Controller al Model), DTOs, Mappers, validaciones con Jakarta y manejo global de errores (400, 404, 500). Probado en Postman
